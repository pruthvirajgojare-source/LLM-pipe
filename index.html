Step 1

Text Input & Tokenization

Computers do not understand letters or words directly. Before a Language Model can process any prompt, the text is split into small pieces called tokens (words, sub-words, or punctuation marks). Each token is then looked up in a vocabulary table to get a unique Token ID number.
